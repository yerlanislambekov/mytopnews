# Daily News Digest → Telegram (GitHub Actions)

Каждый день в 07:00 по Алматы (02:00 UTC) этот workflow сам:

1. собирает свежие заголовки по Казахстану и миру из RSS (без ключей и без вашего ПК);
2. отправляет их в Claude (Anthropic API), который пишет дайджест в том же формате, что и раньше;
3. рассылает дайджест всем получателям из `recipients.json` через Telegram Bot API;
4. сохраняет копию дайджеста в папку `digests/` в этом репозитории.

Работает полностью на серверах GitHub — ваш компьютер может быть выключен.

## Настройка (один раз)

1. **Создайте приватный репозиторий на GitHub** (например `mynews-digest`) и загрузите в него все файлы из этой папки, сохранив структуру (включая `.github/workflows/daily-digest.yml`).

2. **Добавьте секреты репозитория**: Settings → Secrets and variables → Actions → New repository secret.
   - `TELEGRAM_BOT_TOKEN` — тот же токен бота, что уже используется в `send_digest.py` (откройте этот файл в папке MyNews, токен указан в строке `BOT_TOKEN = "..."`). Никому, кроме GitHub Secrets, его вводить не нужно.
   - `ANTHROPIC_API_KEY` — ключ с https://console.anthropic.com/settings/keys (раздел API Keys → Create Key). Расход — доли цента за один запуск дайджеста.

3. **Проверьте получателей** в `recipients.json` — список уже перенесён из `names for Mynews.xlsx`. Добавляйте/убирайте получателей прямо в этом файле.

4. **Включите Actions**, если GitHub предложит это сделать при первом коммите workflow-файла.

5. **Проверка**: вкладка Actions → Daily News Digest → Run workflow (кнопка справа) — запустит дайджест прямо сейчас, не дожидаясь 07:00, и пришлёт сообщения в Telegram. Так вы убедитесь, что секреты настроены верно.

## Расписание

Cron `0 2 * * *` = 07:00 Asia/Almaty каждый день. Чтобы изменить время, поменяйте `cron` в `.github/workflows/daily-digest.yml` (время указывается в UTC).

## Источники новостей

По умолчанию используются RSS Google News (по Казахстану и миру) и RSS Tengrinews. Список можно расширить — добавьте URL в списки `KZ_FEEDS` / `WORLD_FEEDS` в `daily_digest.py`.

## Важно

Старая локальная задача Cowork (`daily-news-digest`), которая открывала Проводник и .bat-файл на вашем компьютере, теперь не нужна — этот workflow её полностью заменяет. Не включайте оба механизма одновременно, иначе дайджест придёт дважды.
